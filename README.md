# Todos CRUD

Одностраничный интерфейс для работы с [DummyJSON Todos API](https://dummyjson.com/docs/todos), без сборки и сторонних зависимостей.

## Запуск

Запустите локальный HTTP-сервер в корне проекта:

```powershell
python -m http.server 4173
```

Откройте <http://localhost:4173>. Для запросов к API требуется подключение к интернету.

## Управление с клавиатуры

- Нажмите `/`, чтобы перейти к поиску задач. Быстрый переход работает, когда модальные окна закрыты и курсор не находится в поле ввода.
- Нажмите `Esc`, чтобы закрыть профиль пользователя или окно создания/редактирования задачи. Во время сохранения задачи закрытие через `Esc` заблокировано.

## Возможности

- Просмотр задач с текстом, статусом, аватаром и кликабельным @username исполнителя.
- Создание и редактирование в модальном окне: название, выбор исполнителя из Users API и статус выполнения.
- Профиль пользователя по нажатию на @username: аватар, личная информация и все его задачи с кнопками изменения, удаления и переключения статуса.
- Сортировка по названию А–Я / Я–А через `GET /todos?limit=0&sortBy=todo&order=asc|desc`; поиск по названию и фильтры работают вместе с сортировкой. Локальные изменения сохраняются при её переключении.
- Поиск по тексту, фильтры, сводные счётчики, состояния загрузки/ошибки/пустого списка и уведомления.
- Изменения DummyJSON не сохраняются сервером, поэтому CRUD-результаты отражаются локально до перезагрузки страницы.
- Чистый интерфейс для управления задачами и поддержания рабочего ритма.

Запросы вынесены в `src/todosApi.js` и `src/usersApi.js` ([Users API](https://dummyjson.com/docs/users#users-all)), логика интерфейса находится в `src/app.js`.
